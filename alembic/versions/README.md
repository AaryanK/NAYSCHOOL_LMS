# Alembic Database Migrations

This folder stores individual migration versions (revisions) generated by Alembic.

To generate a new database migration automatically after changing SQLAlchemy models:
```bash
uv run alembic revision --autogenerate -m "description of changes"
```

To apply all pending database migrations:
```bash
uv run alembic upgrade head
```

To downgrade database by one version:
```bash
uv run alembic downgrade -1
```
